# nairium releases

nairium(NovelAI 이미지 생성을 위한 Windows 데스크톱 앱)의 설치 파일과 자동 업데이트 정보만
올리는 저장소예요. 소스 코드는 여기에 없어요.

## 설치

[최신 릴리스](https://github.com/flavorex0000/nairium-releases/releases/latest)에서
`nairium_<버전>_x64-setup.exe`를 받아 실행하세요. 현재 사용자용으로 설치돼요. 설치 파일에
코드 서명이 없어서 처음에는 Windows SmartScreen이 경고할 수 있어요. "추가 정보"를 누른 뒤
"실행"을 누르세요.

설치한 nairium은 새 버전이 나오면 스스로 받아 두고 알려 줘요. 받은 파일은 nairium의 서명이
맞을 때만 설치해요.

## Notes

Installers and the updater manifest (`latest.json`) for nairium, a Windows desktop app for
the NovelAI image API. nairium is not affiliated with NovelAI (Anlatan) or Danbooru. It is
